# Food planner API

Заготовка REST API на Rust, Axum и PostgreSQL. Ручки пока возвращают демонстрационные данные; миграция создаёт основу схемы для пользователей, рецептов, рационов и покупок.

## Запуск

1. Установите Rust (stable) и Docker Compose.
2. В `backend` запустите `docker compose up -d db`.
3. Скопируйте `.env.example` в `.env`.
4. Запустите `cargo run`.

При старте API применяет SQL-миграции автоматически. Сервер слушает `0.0.0.0:3000`.

## Ручки

- `GET /health` — проверка доступности API и соединения с PostgreSQL.
- `GET /api/v1/meal-plan` — демонстрационный план питания.
- `GET /api/v1/shopping-list` — демонстрационный список покупок.

## Подключение Expo

Клиент читает `EXPO_PUBLIC_API_URL`; по умолчанию это `http://localhost:3000/api/v1`. Для физического телефона задайте адрес компьютера в локальной сети, например `EXPO_PUBLIC_API_URL=http://192.168.1.10:3000/api/v1`, и перезапустите Expo. На Android Emulator обычно используется `http://10.0.2.2:3000/api/v1`.

CORS сейчас открыт для локальной разработки. Перед публикацией ограничьте разрешённые origins и замените демонстрационные данные запросами к PostgreSQL.
