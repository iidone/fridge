# Планируй — React Native

## Запуск

```powershell
npm install
npm start
```

Для просмотра интерфейса backend не нужен: приложение использует демоданные, а запросы к API отключены по умолчанию. Чтобы включить API, создайте `.env` с `EXPO_PUBLIC_ENABLE_API=true` и адресом `EXPO_PUBLIC_API_URL`. На Android Emulator используйте `http://10.0.2.2:3000/api/v1`; на физическом телефоне — IP-адрес компьютера в локальной сети. После изменения `.env` перезапустите Expo.

## Структура `src`

- `screens/` — отдельные экраны приложения.
- `components/` — общие UI-компоненты и нижняя навигация.
- `hooks/` — загрузка и состояние данных приложения.
- `services/` — HTTP-клиент API.
- `theme/` — светлая и тёмная палитры.
- `data/` — демонстрационные данные для режима без API.
- `types.ts` — общие типы API и приложения.
